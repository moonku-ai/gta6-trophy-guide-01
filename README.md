An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words citing its sources, a five-stage roadmap to the platinum, missable flags, and a checklist saved in the browser with export/import, filters and a spoiler setting. Static files that open in desktop Chrome with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
